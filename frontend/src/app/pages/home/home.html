Introduction

What is EnthCollab?

EnthCollab is a collaborative project hub designed for programmers, electronics tinkerers, and hobbyist engineers. Instead of letting side-project ideas stall alone, you can publish structured project blueprints, tag required skills, and team up with builders who have complementary expertise.

What are the main features?

Skill-Based Profiles

Add technology and hardware tags to your profile so others—and the AI assistant—can match you with relevant builds.

Structured Project Pages

Document goals, estimated timelines, safety hazards, and lifecycle status in one clean workspace.

Ticket-Driven Collaboration

Split large builds into clear tasks with difficulty ratings so contributors know exactly where to jump in.

Built-in AI Assistant

Brainstorm ideas, check feasibility and hazards, auto-draft tickets, and discover matching teammates.

02

How Projects Work

How to create a project

Navigate to Projects → Create Project (or generate a draft in the AI Assistant and click Use in Create Project). Fill in the project name, description, estimated duration (e.g., 2-3 weeks), skill tags, visibility (Public or Private), and any safety hazards.

What do the project statuses mean?

WIP (Work In Progress)

Active build currently in development and open for collaboration and ticket progress.

Finished

Completed project ready to showcase as a finished portfolio piece.

Frozen

Temporarily paused (e.g., waiting on hardware parts or design review) and can be resumed later.

Cancelled

Archived or discontinued build kept visible for reference and lessons learned.

How to edit your project

Open any project you created from Projects or your Profile → My Projects tab. As the project owner, you can update the description, adjust tags, document newly discovered hazards, switch visibility between Public and Private, or transition the project status as milestones are reached.

What Hazards field is for?

Hazards section in the project highlights any potential safety considerations while working on the project, for example working with high voltages or if some data becomes non-recoverable once deleted. You can put such info in Hazards section and it will be automatically highlighted on the project page.

03

How Tickets Work

What are tickets for?

Tickets break a project down into clear, self-contained tasks, for example writing a sensor driver, designing a PCB schematic, or building a REST endpoint. Each ticket carries a difficulty badge (Easy, Medium, Hard, or Advanced) so contributors can pick tasks matching their experience level.

Ticket lifecycle statuses

Open

Available for any contributor to claim and start working on.

Taken

Currently claimed by a team member who is actively building the solution.

Done

Completed and verified deliverable merged into the project.

How to claim and submit a deliverable

Open a project's ticket board, claim an Open ticket (moving it to Taken), and build the feature or hardware artifact. When finished, share your repository link, pull request, or documentation notes with the project owner and mark the ticket as Done.

04

EnthCollab AI Agent

What does the AI Agent do?

Available from the Agent tab in the top navigation bar, the AI Agent acts as a technical co-planner grounded in your profile skills and live EnthCollab platform data.

Key capabilities

  • Idea Feasibility & Risk Checks: Validate whether a hobbyist software or hardware idea is realistic and surface technical or safety hazards early.
  • One-Click Project Drafting: Generate a complete project name, description, estimated duration, tags, and starter tickets, then send them straight into Create Project.
  • Project & Collaborator Discovery: Ask for open WIP projects matching your tags or find platform members whose skills fit what your build needs.
